# AI Trainer English

Mobile se GitHub pe banane ke liye ready structure.

## App Name:
**AI Trainer English**

## Theme:
Cream + Purple + Pink

## Important Files (Name kahan hai):

1. **strings.xml** → Phone pe dikhne wala naam
2. **AndroidManifest.xml** → Label set hai
3. **settings.gradle.kts** → rootProject.name = "AI Trainer English"
4. **app/build.gradle.kts** → applicationId = "com.aitrainer.english"

## Mobile pe kaise use karein:
1. Code on the Go / CodeAssist install karo
2. Yeh folder GitHub pe upload karo
3. Clone karke build karo

Happy Learning bhai! 🚀
